# Kata 1 — Prácticas de Python

Repositorio con ejercicios y prácticas realizadas durante el bootcamp para reforzar los fundamentos de programación con Python.

## Objetivo

Practicar los conceptos básicos del lenguaje Python y afianzar la lógica de programación mediante pequeños ejercicios.

## Contenido

El repositorio incluye ejercicios sobre:

- Introducción a Python
- Variables y operaciones básicas
- Condicionales `if`
- Bucles
- Funciones
- Repaso general de sintaxis y lógica de programación

## Archivos principales

| Archivo | Contenido |
|---|---|
| `hola.py` | Primeros ejercicios y sintaxis básica de Python |
| `condicional_if.py` | Ejercicios con estructuras condicionales |
| `bucles.py` | Prácticas con bucles y estructuras repetitivas |
| `funciones.py` | Creación y utilización de funciones |
| `intro-python-repaso.py` | Ejercicios de repaso de los fundamentos de Python |

## Tecnologías

- Python 3
- Git
- GitHub
